# Lamplight

Hand shadows that come alive on your wall: a seated, hands-only mixed-reality experience for Meta Quest 3 and 3S, built with the Immersive Web SDK (WebXR).

**Play:** open https://madhavvan.github.io/lamplight/ in the headset's browser and press "Light the lamp".

This repository holds the built web app only. It is published for the Meta VR Start Developer Competition 2026.
